How the fleet is connected

You · Dashboard
Queue tasks, message agents, and watch live state from here.
Dispatcher
The fleet up loop. Delivers each queued task to its target agent once that agent is idle, then watches it through to done / failed.
Manager ·
A worker with a coordinator role: breaks goals into tasks, queues them for the workers, and unsticks stuck ones (peek / message / restart).
Ungrouped
Every agent is an independent claude terminal (ConPTY on Windows, tmux elsewhere) running in the project directory; the orchestrator talks to each over a localhost control socket. You and the global manager queue tasks; each project manager (PM) coordinates only the workers in its own project. The dispatcher delivers each queued task to whichever agent is idle and tracks it to completion. Agents don't message each other directly — they coordinate through the shared task queue and their PM (or the manager).
